# 소리 사냥꾼 (Sound Hunter)

화면을 보지 않고 **소리만 듣고** 하는 게임입니다. 이어폰(스테레오)을 끼고 눈을 감고 하세요.

- 괴물이 **왼쪽 / 앞 / 오른쪽 / 위 / 아래** 중 한 곳에서 다가옵니다. HRTF 3D 입체음향이라 소리가 그 방향에서 들립니다.
  가까워질수록 소리가 커지고 또렷해집니다.
- 이어폰에서는 3D 음향만으로 위·아래를 구분하기 어려워서, 방향마다 괴물 소리도 다릅니다.
  - 옆·앞: 걷는 괴물 (발소리 + 그르렁)
  - 위: 날개 달린 괴물 (날갯짓 + 높은 끽끽 소리, 밝은 소리)
  - 아래: 땅 파는 괴물 (쿵쿵 + 흙 긁는 소리, 낮고 먹먹한 소리)
- 소리 나는 쪽을 공격하세요. 멀리 있을 때 맞힐수록 점수가 높습니다.
- 괴물이 도착하면 목숨 1개를 잃습니다(처음 3개). 목숨이 2개 이하면 심장 소리가 들립니다.
- 레벨(5마리마다 오름):
  - 1: 왼쪽·앞·오른쪽만
  - 2: 위·아래 추가
  - 4: **종소리 친구** 등장. 때리면 목숨을 잃고, 도착하게 두면 목숨을 1개 얻습니다.
  - 6: 두 마리가 동시에 올 수 있습니다.
- 처음에 다섯 방향 소리와 괴물 세 종류를 미리 들려줍니다.
- 점수·레벨·결과는 음성(한국어 TTS)으로 알려줍니다. 화면에는 아무것도 나오지 않습니다.

## 조작

| | PC | 휴대폰 |
|---|---|---|
| 시작 / 설명 건너뛰기 | 스페이스 | 화면 톡 누르기 |
| 왼쪽 / 오른쪽 | ← / → (A / D) | 왼쪽 / 오른쪽으로 밀기 |
| 위 / 아래 | ↑ / ↓ (W / S) | 위 / 아래로 밀기 |
| 앞 | 스페이스 (F, Enter) | 톡 누르기 |
| 현재 점수 듣기 | R | 두 손가락으로 누르기 |
| 일시정지 | P 또는 Esc | (앱을 벗어나면 자동 일시정지) |

## 실행

`index.html` 파일 하나로 되어 있습니다. 브라우저(크롬·엣지·사파리)로 열면 바로 됩니다. 설치할 것은 없습니다.
휴대폰에서 하려면 이 파일을 아무 웹 서버(예: GitHub Pages)에 올려서 주소로 여세요.
