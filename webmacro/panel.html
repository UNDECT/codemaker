업무 사이트 설정

  1. 업무 사이트 주소 입력 → 이 사이트로
  2. 화면 탭 → 조작에서 직접 로그인 → 로그인 상태 저장
  3. 화면 탭 → ● 녹화 → 할 일을 한 번 직접 해보기 → 녹화 끝 → 언제 실행할지 고르기
  4. 여기서 시험(클릭 없이 확인) → ▶ 시작
